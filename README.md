# RESERVAS-MONOLITO-U

Estructura base de un monolito para reservas: documentación de sus tres áreas y stubs vacíos, sin lógica de negocio.

## Estructura

- [funciones](funciones/funciones.mmd): operaciones del negocio de reservas.
- [interfaz](interfaz/interfaz.mmd): punto de contacto con el exterior.
- [datos](datos/datos.mmd): información y acceso a datos.

## Uso

```bash
python main.py
```
